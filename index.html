Hướng Dẫn Chia Sẻ Web & Nộp Bài

Tải file HTML rồi đưa lên dịch vụ hosting.

1. Netlify Drop

  1. Tải index.html.
  2. Truy cập Netlify Drop.
  3. Kéo thả file vào trang.
  4. Nhận link web.

2. GitHub Pages

  1. Tạo repository.
  2. Upload index.html.
  3. Vào Settings → Pages.
  4. Chọn branch main và lưu.

3. Vercel

  1. Đăng nhập Vercel.
  2. Import project.
  3. Đặt file HTML là index.html.
  4. Deploy.
